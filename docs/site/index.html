02 / Start with regtest

A local node. A real starting point.

Use a fresh test directory and a loopback HTTP listener. No production migration or real wallet keys are needed for this evaluation.

Terminal 1 · pinned source · local evaluation
git clone https://github.com/gosuda/bitcoin-rs.git
cd bitcoin-rs
git checkout --detach f599c9d5906f999e35fed86ab6cd1f247d051a3a
cargo build --locked --profile quickstart -p bitcoin-rs \
  --no-default-features --features fjall
RUN_DIR="$(mktemp -d "${TMPDIR:-/tmp}/bitcoin-rs-eval.XXXXXX")" &&
  printf 'Evaluation directory: %s\n' "$RUN_DIR" &&
  ./target/quickstart/bitcoin-rs \
    --network regtest \
    --scriptindex=full \
    --data-dir "$RUN_DIR/state" \
    --rpc-bind 127.0.0.1:18443

Before running: the reviewed workspace requires Rust 1.95.0 or newer. This minimal native lane selects only fjall. Commands were source-reviewed, not executed here. Stop on any failure; verify the full path on your platform.

Next: keep the process running, query getblockchaininfo on port 18443, then test shutdown and restart with the same printed directory. HTTP 200 alone is not JSON-RPC success. Read setup and authentication guidance ↗
