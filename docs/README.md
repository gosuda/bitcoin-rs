## Evidence and implementation status
External evidence lives in [ecosystem-compat.toml](api/ecosystem-compat.toml) under the [ecosystem compatibility contract](contracts/ecosystem-compatibility.md). Registry status is not external verification. Do not conflate the two. [Formal models](models/) obey the [formal verification contract](contracts/formal-verification.md). A compiled build is not proof of a target design. The default binary is kernel-free. Library defaults follow [validation-default.md](contracts/validation-default.md). The optional `kernel` lane does not imply native-default promotion. The node runs BIP324 v2 transport by default. `--v2transport=false` keeps every connection on v1. `P2pServiceConfig::default()` leaves v2 transport off. Live bidirectional Core 31.1 interop is recorded ([BIP adoption](policies/bip-adoption.md), BIP 324 row in [bip-support.md](bip-support.md)).
